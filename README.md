## 📖 About The Project

**Youbo Ograni (ইউবো অগ্রণী)** is a fully **Gen-Z supported** Bengali social organization dedicated to **developing society** through various impactful initiatives. This is the official single-page website that showcases the organization's vision, mission, activities, and achievements.

The organization focuses on three core pillars:

- 🎓 **শিক্ষা সহায়তা (Education Support)** — Awarding meritorious students who secured 1st, 2nd, and 3rd positions in Madhyamik examination from local schools.
- 🌳 **পরিবেশ রক্ষা (Environment Conservation)** — Regular tree plantation drives, free sapling distribution, and environmental awareness campaigns.
- ❤️ **সমাজ সেবা (Social Welfare)** — Community events, bringing people together, fostering harmony, and non-political community building.

## ✨ Key Features

- ✅ **Fully Responsive Design** — Works perfectly on mobile, tablet, and desktop devices.
- ✅ **Auto-Sliding Members Carousel** — Showcases special members with designations (Secretary, President, Vice President, Treasurer, Event Coordinator).
- ✅ **Interactive Photo Gallery** — 12+ images with hover zoom effects showcasing award ceremonies, tree plantation, and community events.
- ✅ **Contact Form with Validation** — Bengali form fields with validation alert.
- ✅ **Smooth Scrolling Navigation** — Sticky navbar with smooth section transitions.
- ✅ **Back-to-Top Button** — Floating button for easy navigation.
- ✅ **Sticky Navbar** — Transparent-to-solid background transition on scroll.
- ✅ **All Bengali Content** — Fully localized in Bengali language.
- ✅ **Single File Implementation** — Entire website in one HTML file (HTML + CSS + JS).
